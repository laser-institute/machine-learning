# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Educational curriculum for supervised machine learning (SML) in STEM education research, part of the LASER Institute. Contains four modules plus a microcredential, with materials in both R and Python.

## Structure

Each module (`module-1/` through `module-4/`) contains:
- `sml-N-conceptual-overview.qmd` — RevealJS slide deck (presentation)
- `sml-N-code-along.qmd` — RevealJS slide deck (live coding)
- `sml-N-case-study.qmd` — HTML document (R version, student-facing with blanks)
- `sml-N-case-study-key.qmd` — HTML document (R answer key)
- `sml-N-case-study-python.qmd` / `sml-N-case-study-key-python.qmd` — Python equivalents
- `sml-N-readings.qmd` — Reading discussion questions
- `sml-N-badge.qmd` — Assessment/reflection activity
- `data/` — Module-specific datasets (CSV files)

## Rendering

All `.qmd` files are Quarto documents. Render individual files with:
```
quarto render module-1/sml-1-case-study.qmd
```

Conceptual overviews and code-alongs render to RevealJS slides. Case studies and badges render to HTML documents.

## Key Technologies

- **R**: tidymodels (recipes, parsnip, rsample, tune, workflows, yardstick), tidyverse, ranger, xgboost, vip
- **Python** (via reticulate): scikit-learn, pandas, numpy, statsmodels
- **Quarto**: Document rendering engine; slide decks use `format: revealjs`, documents use `format: html`
- **pacman**: R package loading via `pacman::p_load()`

## Datasets

- **Module 1**: IPEDS (Integrated Postsecondary Education Data System) — higher education institution data
- **Module 2**: OULAD (Open University Learning Analytics Dataset) — student course data
- **Module 3**: OULAD with additional variables
- **Module 4**: OULAD interaction-level data (gitignored due to size; generated by `module-4/process-interactions-data.R`)

## Curriculum Progression

1. Foundations: explanation vs. prediction, linear regression in tidymodels
2. Training/testing splits, workflows, logistic regression
3. Confusion matrix, precision/recall/F-score/AUC, random forest
4. Feature engineering, cross-validation, boosted trees (xgboost)
